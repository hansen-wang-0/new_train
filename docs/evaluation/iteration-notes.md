# 迭代记录

这轮迭代主要做了 4 件事：

## 1. 把“整段后拆块”改成“先定块，再逐块生成”

原因：

- 以前是让模型回一大段，再硬拆成卡片
- 这样每张卡片的边界是假的
- 结果会显得像一篇作文被切碎

现在：

- 描写扩展器固定为 4 块
- 联想短路器固定为 4 块
- 视角转换器固定为 5 块
- 每一块单独请求模型

## 2. 收藏补上原始输入

现在收藏里会保留：

- 生成内容
- 原句 / 原始词组 / 原始事件
- 生成时间

复盘时不再只看到结果，而能看到它是从什么地方长出来的。

## 3. 联想训练从“箭头路径”改成“关系型连接”

这轮发现最难的模块就是联想。

问题在于：

- 模型很容易偷懒
- 只是把两个词塞进同一场景
- 看起来像连上了，其实没有真正建立关系

为了解决这个问题，这轮做了三次收紧：

1. 明确要求不要只同框，要有关系
2. 加入“现实、日常、可信”的限制
3. 加入好例子 / 坏例子，让模型知道什么叫合理连接

目前联想结果已经比最初自然很多，但依然是系统里最值得继续打磨的一块。

## 4. 建立了本地评估脚本

新增：

- [`scripts/evaluate-training.mjs`](../../scripts/evaluate-training.mjs)

作用：

- 用固定样例批量跑模型
- 把结果保存到 `docs/evaluation/`
- 让迭代不再只靠感觉，而能看输出变化

## 这轮之后的判断

### 已经明显变好的

- 收藏信息完整了
- 结构更像训练器，不像拼接器
- 描写扩展器的结果更稳定
- 视角转换器的边界更清楚

### 还需要继续盯着的

- 联想短路器在“特别不相干”的词组上，仍然会偶尔走偏
- 温柔视角偶尔会变成泛安慰
- 个别模型输出还会偷偷带编号

这也是接下来最值得继续压的三件事。
