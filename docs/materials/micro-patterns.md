# 微型表达模板卡

这份不是理论，是你可以直接套着练的短模板。

用法很简单：

- 先写你的原句
- 选一个模板
- 不求高级，只求从“太直”走到“稍微有画面”

## 1. 把抽象感受变成身体反应

原句：

- 我很紧张
- 我今天很累

模板：

- 这不是单纯的 `情绪`，更像 `身体或动作反应`
- 我不是 `某种感觉`，我是 `某种运行状态`

例子：

- 这不是单纯的紧张，更像脑子里一直有人来回拉警报。
- 我不是累，我像是电量还亮着，但系统已经开始卡顿。

## 2. 把东西拟人化

原句：

- 今天雨很大
- 这个消息一直没回

模板：

- `对象` 像一个 `某种性格的人`
- `对象` 今天像是在 `做某件事`

例子：

- 雨今天像个不太讲道理的人，一来就不准备客气。
- 那条消息像故意躲起来，明明在那儿，就是不肯出来见人。

## 3. 用“像什么”打开画面

原句：

- 太阳很亮
- 地铁里人很多

模板：

- 像 `具体物件`
- 像 `一个动作中的场面`
- 像 `一种有情绪的环境`

例子：

- 太阳亮得像有人把探照灯直接拧到了头顶。
- 地铁里的人多得像一群被时间推着走的鱼。

## 4. 轻一点地说，不要硬搞笑

原句：

- 我今天状态不好
- 这个会开得很久

模板：

- 我今天最大的优点，大概是 `某种勉强维持`
- 这件事不像 `正常描述`，更像 `一个轻微夸张的判断`

例子：

- 我今天最大的职业素养，就是看起来还像在线。
- 这个会不像在开会，像大家把下班时间放进了共享文档。

## 5. 用反差把句子抬起来一点

原句：

- 他嘴上说不急
- 大家都很安静

模板：

- 表面上 `A`，实际上 `B`
- 看起来 `A`，底下却 `B`

例子：

- 他嘴上说不急，语速已经替他急完了。
- 大家看起来都很安静，底下的情绪像一锅快开的水。

## 6. 用旁观者口气说自己

原句：

- 我又拖延了
- 我开会的时候一直点头

模板：

- 一个成年人又在 `做某种有点好笑的事`
- 这看起来像 `行为`，其实更像 `心理状态漏出来了`

例子：

- 一个成年人又在用刷新页面的方式处理人生了。
- 这看起来像在认真开会，其实更像脑子临时掉线后的礼貌自救。

## 7. 练习时最重要的标准

- 不要追求“文艺”
- 不要追求“句句都惊艳”
- 只追求比原句多一点具体、多一点动作、多一点人味

如果你每次只把一句话改好 10%，一个月后差别会非常明显。
