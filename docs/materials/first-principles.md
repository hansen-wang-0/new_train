# 训练的第一性原理

如果把“变得更有趣”拆到最底层，它其实不是一个抽象人格目标，而是三条能力链：

1. `看到`
2. `连起来`
3. `说出来`

这份文档就是把这三条链拆开。

## 一、观察不是多看，而是看差异

真正值得记下来的小事，通常至少满足一条：

- 有反差：嘴上说不急，语速却很快
- 有错位：便利店灯光很暖，但买东西的人都很疲惫
- 有小尴尬：明明没话，却还在维持聊天
- 有隐藏动作：一个人点头，不一定代表认同，也可能只是礼貌自救
- 有情绪漏出来：说“没事”的方式，本身就是事

所以观察时最该问的不是：

- 发生了什么

而是：

- 它哪里不完全对劲
- 它暴露了人什么习惯
- 它像什么
- 它背后其实是哪种处境

## 二、联想不是瞎扯，而是找真实关系

两个词能连起来，通常靠这几种关系：

### 1. 场景关系

它们会不会在同一段生活里出现。

例子：

- 电梯 和 沉默
- 雨伞 和 门口

### 2. 前后顺序

不是同时出现，而是一个自然地引出另一个。

例子：

- 牙刷 和 地铁
  先刷牙，再赶地铁

### 3. 功能关系

它们是不是都在完成某种类似的任务。

例子：

- 冰箱 和 夜晚
  都像在帮情绪降温

### 4. 角色关系

它们像不像生活里同一种角色。

例子：

- 地铁 和 闹钟
  都是不会顾及你心情的推进器

### 5. 情绪关系

它们是否都指向同一种状态。

例子：

- 月亮 和 冰箱
  都有一种清冷、安静、略带孤独的气息

### 6. 反差关系

把两个不该放一起的东西放一起，反而会冒出意味。

例子：

- 西装 和 睡意
- 会议 和 胃痛

真正糟糕的联想，不是“不高级”，而是：

- 只是把两个词硬塞进同一场景
- 没有关系，只有同框
- 没有动作，没有情绪，没有机制

## 三、表达不是更文艺，而是更具体

一个句子变得“更像人”，通常靠下面几种改动：

### 1. 抽象变具体

- 我很累
- 我像靠惯性续命

### 2. 感受变身体

- 我很紧张
- 肩膀一直吊着，像放不下来

### 3. 结论变画面

- 太阳很亮
- 亮得人下意识眯眼

### 4. 说明变比喻

- 大家都在赶时间
- 人群像被时钟驱赶的鱼

### 5. 严肃变轻一点

- 我状态不好
- 我今天最大的职业素养，就是看起来还在线

## 四、训练时最重要的判断标准

不是“高级不高级”，而是下面这三个问题：

1. 它是不是比原句更具体
2. 它是不是更像人在说话
3. 它是不是给了我一个新的角度

只要这三条里能多占一条，这次训练就值。

## 五、你可以每天只抓这三个问题

白天碰到任何小事，都只问：

1. 这里面哪里有一点不对劲
2. 这件事可以通过什么关系连到别的东西
3. 这句话如果不直说，还能怎么说

问久了之后，你的大脑会开始自动出现第二种说法。
