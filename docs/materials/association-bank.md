# 联想样本库

这份文档不是标准答案，而是给你看“两个词可以通过哪些方式连起来”。

每组我都给 4 种版本：

- 一句话
- 前后顺序
- 小故事
- 比喻

## 1. 牙刷 和 地铁

一句话：

- 牙刷把人从睡意里拎出来，地铁把人从家里拎进一天。

前后顺序：

- 她刚刷完牙，嘴里那点薄荷味还没散，就一路小跑去赶地铁。

小故事：

- 他出门太急，到了地铁站才发现自己嘴里还是刚刷完牙的凉味。那一瞬间他突然觉得，早晨其实还没真正开始，只是身体已经被送上路了。

比喻：

- 牙刷和地铁，都是清晨那种不问你愿不愿意、只负责把你往前推的小装置。

## 2. 月亮 和 冰箱

一句话：

- 月亮挂在窗外，冰箱亮在厨房里，它们都像深夜保留下来的冷光。

前后顺序：

- 她半夜起床找水喝，先看见窗外的月亮，后来又被冰箱门里的冷光照了一下，整间屋子都像轻轻醒了一次。

小故事：

- 他打开冰箱找夜宵，冷气扑出来的一瞬间，正好看见窗外的月亮。那两种光一里一外，像是深夜给人的两种陪伴，一种远，一种近。

比喻：

- 月亮像天空的冰箱，冰箱像厨房里的小月亮，它们都在帮夜晚把热闹降温。

## 3. 电梯 和 沉默

一句话：

- 电梯里的沉默，总像一群人被迫共享几秒钟的陌生。

前后顺序：

- 门一关上，大家都安静下来，电梯开始往上走，沉默也像被一起运上去了。

小故事：

- 两个人一前一后进了电梯，谁都没有看谁。楼层数字一格格跳，空气却比数字慢，像谁也不想先承认这几秒钟有点尴尬。

比喻：

- 电梯和沉默都像封闭空间里的临时停顿，把人短暂地困在自己身上。

## 4. 耳机 和 逃跑

一句话：

- 有时候耳机不是用来听歌的，是用来把自己从外界里撤走的。

前后顺序：

- 她刚听见办公室里有人开始争论，就把耳机戴上了，像给自己拉下一道小小的逃生门。

小故事：

- 地铁上太吵，她把耳机塞进去，音乐还没响，心已经先退后一步了。那一瞬间她不是在听歌，更像是在撤离。

比喻：

- 耳机像一种便携式逃跑，把人从现实里临时抽离半寸。

## 5. 西装 和 睡意

一句话：

- 西装穿得再利落，也盖不住一个人眼皮底下那点睡意。

前后顺序：

- 他出门前把西装拉平，进电梯时却已经在偷偷打哈欠，体面和疲惫几乎是同时出门的。

小故事：

- 会议室里他坐得笔直，袖口也很干净，可眼神还是像昨晚没睡完。西装先到了白天，睡意却还拖着半个夜晚。

比喻：

- 西装和睡意像一个人身上的两种制度，一个要求你上线，一个提醒你其实还没醒。

## 怎么用这份样本库

别背。

你只要做两件事：

1. 看它是用哪种关系连起来的
2. 把其中一组换成你自己的词，再写 1 个版本

真正要学的不是答案，而是搭桥的方法。
