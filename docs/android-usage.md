# 安卓使用说明

现在这套工具已经做成了可安装的 PWA，也就是“网页形态的 App”。

它在安卓上的使用方式有两种：

## 1. 最快的方式：同一 Wi‑Fi 下直接安装

适合你现在立刻就想在自己手机上用。

### 步骤

1. 在电脑里进入这个项目目录
2. 运行：

```powershell
node server.mjs
```

3. 查电脑当前的局域网 IP

```powershell
ipconfig
```

找你当前 Wi‑Fi 网卡对应的 IPv4 地址，比如：

```text
192.168.31.24
```

4. 确保手机和电脑在同一个 Wi‑Fi
5. 在安卓 Chrome 打开：

```text
http://你的电脑IP:4173
```

例如：

```text
http://192.168.31.24:4173
```

6. 打开后点击页面里的 `安装到手机`

如果没看到按钮，也可以在 Chrome 菜单里选择：

- `添加到主屏幕`

安装后会以全屏 App 形式运行。

## 2. 更稳定的方式：后面部署到公网

如果你以后想不依赖电脑、随时在手机上打开，就需要把它部署出去。

最简单的路线是：

- 前端和 Node 服务一起部署到一台云服务
- 然后手机直接访问 HTTPS 地址
- 再把它安装到主屏

这样会比现在更像一个真正独立的 App。

## 这版已经有的安卓能力

- 可安装到安卓主屏
- 全屏运行
- 有应用图标
- 支持离线打开基础界面
- 手机端按钮和布局已经做了单列优化

## 这版还不等于什么

它还不是一个原生 APK。

如果你下一步想要真正的安卓包，有两条路：

1. 用 `Capacitor` 包成原生壳，再出 APK
2. 继续把 PWA 打磨好，然后用 `TWA` 或原生 WebView 壳来封装

## 我建议的顺序

先用这一版 PWA 验证你到底会不会真的高频使用。

因为只有训练流程真的稳定了，做原生壳才值得。
