有趣训练场

这不是替你说话的工具，而是一套把“观察、联想、改写、复盘”练成习惯的小系统。

今日练习

  • 记录 3 个小瞬间
  • 选 1 个瞬间做视角改写
  • 练 1 组双词联想
  • 收藏 1 句你真心想学的表达

安卓上可通过 Chrome 的“添加到主屏幕”安装。

模式设置

默认预填 DeepSeek 兼容接口。填入你的 Key 后，可以得到更丰富、也更发散的生成结果。

公网安全模式： 这套网页适合部署成“每个人自己填自己的 API Key”。 你的 Key 不会写进代码仓库，也不会自动共享给别的访问者。

当前为本地启发模式。

说明：这里填入的 Key 只保存在当前浏览器本地。别人打开同一个公网网址时，需要填他们自己的 Key。

描写扩展器

把一句平铺直叙的话，改写成更具体、更有画面、更像“你自己”的表达。

这里会出现近义词、比喻、拟人和不同风格的改写结果。

联想短路器

用两个不相干的词练习搭桥。它们不一定是物体，也可以是情绪、制度、关系、抽象概念，再把它们连成一句话、一个比喻，或者一个很短的小故事。

灯 和 地铁

先自己想，再看提示和答案。不是求唯一正确，而是求你能不能迅速搭桥。

视角转换器

同一件事，换个视角就会换一套说法。

这里会从小孩、旁观者、导演、喜剧人等角度帮你重写这件事。

收藏与复盘

把原句和改写一起留下来。复盘不是只看结果，而是看它是从哪一句直白的话长出来的。

你收藏的句子会出现在这里。

历史记录

每一次查询都会留痕。刷新之后，你的最近输入和结果也会自动恢复。

你每次生成的结果会出现在这里。

默认练法

如果你明天只想快速上手，就按这个顺序来。

  1. 先在“描写扩展器”里输入一句你最常见的直白表达。
  2. 挑 1 句你喜欢的改写，存进收藏。
  3. 做 1 次“联想短路器”，优先练一句话、一个比喻、一个小故事。
  4. 用“视角转换器”重写今天一件很小的事。
  5. 睡前或起床后翻一次收藏，让它变成你自己的语言肌肉。
